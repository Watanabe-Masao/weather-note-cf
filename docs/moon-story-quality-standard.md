# 満月の物語：品質の基準書

満月の絵本が満たすべき品質。進め方は [moon-story-quality-process.md](moon-story-quality-process.md)（手順書）、作り方の技術は [moon-story.md](moon-story.md)。
制作の詳しい基準（美術・文学の決まりと、測った値・経緯）は Project「満月の絵本_制作基準」（v3.2）。この基準書は、そのうち「合格かどうかを確かめられるもの」を、リポジトリで守る形にまとめたもの。

- **作品ごとに決めること（そろえない）**：本文・言葉の量・反復と呼応、ページごとの秒・本編の長さ・余韻、視点の動き・倍率、光の色、後半の空間の骨格、沈黙の置き方、終幕の形。下の基準は「どう確かめるか」で、「いくつにするか」ではない。
- 【必須】は満たさないとマージしない。【目標】は満たさないときに理由を PR に書く。

## 1. 時間軸の整合性

- 【必須】絵・文字・視点の移動は、作品の演出（`<作品>Direction.ts` の秒と、そこから写した拍）という一つの時間軸に合わせる。場面の側で、別の区切り（ページの頭の整数の拍など）に丸めない。
- 【必須】秒で決める本では、ページ i の区間は前のページの止まる所（i − 1 + `BEAT_REST`）から始まる。場面の動きと合図は、その区間の中で受け付ける（合図を切り上げると絵が言葉より遅れる。PR #524 の 2P・3P）。
- 【必須】演出の秒は一か所にまとめ、絵の動きと文の時刻が同じ値を参照する（二重に持たない）。
- 【必須】合図の言葉は本文にあり、出る順に並ぶ。合図は場面の受け付ける範囲にある（テストで見張る）。

## 2. 描画結果の同等性

- 【必須】見本で承認された表現は、本番でも同じに見える。CSS やコードを規約に合わせて書き換えたら、前後の実際の描画（字の明るさ・位置・重なり）を比べる。
- 【必須】字幕の色・透け具合は本の変数（`--bk-*`）、重なりは層の決まり（`z-index` 0〜3 か `var(--layer-*)`）。字幕の中の重なりは、沈め 0・字 1（字は子孫として指す）。
- 【必須】`test/ui/hardcode.test.ts`・`test/ui/tokens.test.ts` を緩めない。

## 3. 再生の可逆性

- 【必須】同じ時刻では、自動で読んでも、手で進めても戻っても、ドットで途中のページへ移っても、同じ状態（見えている字・節・絵の部品・視点・額縁）になる。`story-qa.py stops` で、止まる所ごとの行きと帰りが一致する。
- 【必須】「止める」はその場で止まり、再開は止めた所から同じ速さ（PR #522）。ドットで選んだページは冒頭から読める。最後のページは結末の文から（PR #519）。
- 【必須】節のあるページで、二つの節が同時に見えない。消えた節が残らない。

## 4. 表示環境への適応

- 【必須】確かめる画面：320×568・375×667・390×844・430×932。取り残しの字（1〜2 字だけの列）・操作ボタンとの重なり・画面の外の字が無い（`story-qa.py layout`）。
- 【必須】横向き（667×375・844×390）と 320×568 で、字が画面の外へ出ない（`story-qa.py env`）。画面の外へ出る計算の領域（左上など）は縦長の画面だけに効かせる。
- 【必須】動きを減らす設定：字幕は横書きで並べ、節は順に全部見せる。"/" を強制の改行にしない（縦書きの列のときだけ折る）。物語の中心の絵は止まった絵で見せ、代替テキストをつける。
- 【必須】読み上げは本文をそのまま一度（組版の印 "/" は読まない）。作品名も読み上げる。ボタン類は 44px 以上。
- 【目標】字と後ろの明るさの比 4.5:1（字が出そろった所で、同じページを 2〜3 回測る）。主役（月など）と字・操作ボタンのすき間は、動き全体で 5px 以上（10px 以上を推奨）。

## 5. 文字組み

- 【必須】作品全体で字の大きさをそろえる（同じ端末でページごとに縮めない）。19px 未満にするときは、理由と比較の画像を添えて相談する。
- 【必須】収まらないときは、意味のまとまりで折る（行が列に収まらないときだけ）→ 字幕の領域 → 列の間 → 作品全体で縮める、の順。
- 【必須】場面ごとの字幕の設定（`StoryScene.captions`：字の調子・沈め・領域・出はじめの高さ・halo・titleDrop）は、動きのある表示のときだけ効かせる。共通の部品に作品の番号を書かない。

## 6. 言葉と動きの同期

- 【必須】擬音と動作は同時。自然現象（月の出・夜明けなど）は言葉より先に起き、言葉が追いかける。前のページの構図の上に、次のページの字を出さない。
- 【必須】因果の順（置く → 使う、光が届く → 照らされる）を動きの記録で確かめる。

## 7. 光と色

- 【必須】局所の光（縁の光・主役を照らす光）と世界全体の光（夜明け）は、時間で分ける。局所の光のあいだは背景の暗さを保つ。順はテストで守る。
- 【目標】光のマスクは役割ごとに多くても 3 つ。光の向きは一つ。マスクの縁はぼかす。色の流れは作品全体で設計し、朝を始まりの色に戻さない。

## 8. 終幕

- 【必須】最終ページ：最後の字が出そろう → 読む → 字が完全に消える →（作品名）→ 額縁。額縁のきっかけは字が消え終わったこと。作品名と額縁が同時に見えない。
- 【必須】作品名を最後の節にするときは、本文が消えて絵だけの時間を置いてから出す。

## 9. テスト（どの作品も持つ）

- 【必須】作品の演出の回帰テスト（`test/data/story-direction-<作品>.test.ts` など）に、少なくとも次を入れる：
  - 承認された間と字のない時間（秒）。
  - 光・視点の順（場面の動きを記録して、始まりと終わりの拍を比べる）。
  - 節の順と、前の節が消えきってから次の節が出ること。
  - 額縁は最後の文が消えきってから。
  - 合図の言葉が本文にあり、順に並び、場面の受け付ける範囲にあること。
- 【必須】字の時刻は、組版の印（改行・"/"）を除いた字の数だけ（折っても時間は変わらない）。
- 【必須】共通の処理（`direction.ts`・`MoonStory.tsx`・字幕の CSS）を変えたら、ほかの作品の回帰テストと e2e の event、`story-qa.py` の測定を通す。
- 【目標】設定の値をなぞるだけのテストにしない。できるだけ、場面の動きの記録や画面の状態で確かめる。

## 10. 素材

- 【必須】素材の画素は「画面で表示する最大の大きさ × 3」以上。寄りの構図では拡大 1.0 倍まで。
- 【必須】本番の素材は、元の PNG を `design-src` に、配信用を `storyAssets.ts` に登録する。画面から切り出した止まった絵も元を残し、場面を変えたら撮り直す。
- 【必須】使わなくなった素材の整理は、本番化の PR に混ぜない。原画・制作素材は残し、参照の無い配信用の素材と不採用の設定を、参照を調べた独立した PR で削除する（削除は一つずつ確認）。

## 11. 科学・文化

- 【必須】事実・出典管理シートで「事実・伝承・創作」を分け、新しい描写（絵の中の自然現象も）を足したら照合する。
- 【必須】本番化の前に、物語の描写と「自然と科学」「あとがき」の文を、一次に近い出典（天文台・NASA・政府の野生生物の解説・鳥類学の機関・大学の研究の解説）で照合し、Project に記録する。
- 【必須】照合の結果で物語の本文を説明的にしない。名前の由来などは、特定の民族に安易に帰属させない。

## 12. 作品レビューの配点

- 物語・構成 25／文章・文学性 25／挿絵・美術 20／読書体験・演出 10／独自性 10（計 90）。科学・文化的正確性 10 は原典照合のあとで評価する。
- 読書体験・演出の点は設計と録画への評価で、実機の性能は含まない（実機は別に確かめる）。
- 参考：ビーバームーン 83／90、コールドムーン（第3次）86／90。
