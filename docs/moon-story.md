# 満月の物語（絵本）の作り方と品質の決まり

2026-11-20 渡辺さんの OK（ビーバームーンの第3版 #386、表紙・本棚・ページ送りの #390、仕上げ）を基準の品質とし、ほかの満月へ横展開するための決まり。
画面は `src/ui/MoonStory.tsx`、絵と動きは `src/design/story/`、文は `shared/fullMoonNames.ts` の `tale`。

## 1. 体験の流れ（どの満月も同じ）

「本を開く → 物語に入る → 満月を見る → 天文情報を知る」を、途切れない一つの動きにする（16:45 のレビュー）。

| 段 | 見せ方 | 作り |
|---|---|---|
| 本棚 | 一年の満月の本が並ぶ。背を押すと取り出して開く | 共通（背の絵だけ場面ごと） |
| 表紙 | 紺の革・金の三重の枠・四隅の飾り。名前は金の箔押しの明朝、その下に「— English Moon —」。真ん中に場面の絵（山・森・川・主役・大きな満月） | `Book.tsx`（共通）。絵は場面ごと（`CoverArt`・`coverCorner`） |
| 見開き | 表紙は背でつながったまま起き上がり、裏が左へ倒れる。右のページに「窓」とひと言 | 共通。窓の絵は場面ごと（`Window`） |
| 物語に入る | 窓の中へ寄り、窓の空の色で画面を覆ってから、場面が溶けて現れる（紙一色の画面をはさまない） | 共通。空の色は場面ごと（`sky`） |
| 場面 | 一枚の続いた世界を、物語の一文ごとに一コマ。文は明朝の縦書きで空に、一字ずつにじみから浮かぶ | 場面ごと（`World` と `build`） |
| 締めくくり | ひと言をもう一度（読点で改行）、まわりで小さな星が瞬く | 共通 |
| 移る間の一言 | （11/21 削除。絵本は最後のページの余韻からそのまま、あとがきへ移る） | ― |
| 天文情報 | 物語の満月が「満月になる時刻」のカードの月へ移る。その夜の空のカード（通り道・出・高い・入り） | 共通（`EventInfo.tsx`） |
| 知識 | 名前の由来・自然との関係を、古い紙のページで（角を内に丸く切った金の二重の枠、最初の字を大きく）。象徴の言葉は小さな絵つきの札。ページの下に淡いセピアの絵 | 共通。下の絵は場面ごと（`PaperArt`）、象徴の絵は言葉ごと（`emblems.tsx` の `SYMBOL_ICONS`） |

物語の演出と天文の値は分ける：場面の絵は文化的なイメージで自由に描き、時刻・通り道・月の出入りは計算の結果だけを出す。

## 2. 場面を一つ足す手順

1. `shared/fullMoonNames.ts` にその呼び名の `tale`（ひと言と文）があることを確かめる。無ければ先に文を用意する（渡辺さんの確認）。
2. `src/design/story/<名前>World.tsx` を作る（`BeaverWorld.tsx` を見本に）。書き出すものは5つ：
   - `<NAME>_BEATS`：文の数（一文が一コマ）。
   - `<Name>World`：場面の SVG。部品は `parts.tsx`（`StoryMoon`・`MoonDefs`・`stars`・`pine`・`SkyGradient`・`rand`）を使う。
   - `<Name>Window`：本のページの窓の絵（最初のコマを小さくしたもの）。
   - `<NAME>_SKY`：最初のコマの空の色（`cssSky(...)`）。窓の空と、場面の最初の空が同じ色であること。
   - `build<Name>Scene(gsap, root, tl, loops)`：コマの動き（`tl` は 0〜コマ数の拍）と、くり返す動き（落ち葉・雪など）。
3. `src/design/story/scenes.ts` の `STORY_SCENES` に呼び名で足す（ブルームーンは「ブルームーン」）。
4. `test/data/story-scenes.test.ts` が通ることを確かめる（コマ数＝文の数、月の目印が一つ、絵に文字なし、窓と空の色）。
5. `npm run build` のあと `python3 scripts/story-capture.py <その満月の日> <出力フォルダ>` で一覧（strip.png）と動画を撮り、見直す（4章）。
6. PR に一覧と動画の所見を書き、渡辺さんの OK のあとにマージ。

## 3. 絵の決まり

- **一枚の続いた世界**：場面を切り替えない。カメラ（`.<p>-camera` の拡大と移動）で寄り・引きをして、一文ごとに見どころを変える。
- **層に分ける**：空（時間ごとに重ねる）・星・満月・遠景・中景・主役・水面・手前・舞うもの（葉・雪・花びら）・枠。それぞれを独立して動かす。
- **主役を見せる**：主役（動物・人・花）が名前の由来を伝えるコマでは、主役に寄り、何をしているかが分かる動き（枝を置く、など）を入れる。
- **満月は一つ**：`StoryMoon` で描く（今夜の情報の月へ引き継ぐ目印が付く。`book` を持つ満月は引き継がず、最後のページの絵に残す ── 下の「絵本の形」）。名前の文のコマで昇り、その前に地平の向こうが明るくなる。昇るにつれて周りを少し沈め、水面があれば月の道を伸ばす。
- **夕暮れから夜は時間差で**：空・水面・木・星を少しずつずらし、二つの文にまたがって変える。
- **文字を絵に描き込まない**（文は画面の側で重ねる）。
- **色はデザインの層だけ**（`src/design/story/`）。画面のコード（`src/ui/`）に色を書かない。月の色は `STORY_MOON` で共通。
- **カメラの決まり**：大事なもの（主役・月・文）が、縦書きの文の場所（右上）と重ならない。下の点（今のコマ）にもかぶせない。
- **科学と文化を混ぜない**：名前は主に北米の季節に基づく呼び名。日本の季節の行事と混ぜない。月の色を名前に合わせて塗らない（ピンクムーンの月はピンクにしない、など）。その年だけのこと（月食など）は場面に入れず、天文情報の側で計算から出す。

## 4. 見直しの仕方（品質の基準）

`scripts/story-capture.py` の一覧と動画で、次を一つずつ確かめる。ビーバームーンの第3版（#386）が基準。

- 表紙：名前が金の箔押しで読める。絵の山・森・川は場面と同じ平たい描き方で、主役と満月が引き立つ。文字と枠の飾りが重ならない。
- 開き方：表紙と裏が背でつながったまま。左右のページは同じ大きさ。
- 入り方：窓 → 空の色 → 場面の最初のコマが、色の段差なしにつながる。
- コマごと：その文の見どころが画面にある（文と絵が合っている）。主役のコマで主役が小さすぎない。
- 文：どのコマでも読める（夕焼けの明るい空でも）。月・主役と重ならない。
- 月：名前の文のコマで昇る。`book` の無い満月は、物語の終わりからカードの月へ途切れずに移る。`book` の満月は最後のページの絵に残り、あとがきの紙が静かに重なる（物語の月は表現、今夜の月は計算）。
- 通しの構図：9ページを続けて見て、主役が小さすぎないか、前景（枝など）が後半のページまで残っていないか（ビーバームーンで出た課題）。
- 動きを減らす設定：場面は一枚の絵（月が昇ったあと）と、文を全部並べて見せる。
- 360px と 390px で、はみ出し・切れがない（`e2e/event.py` も通す）。

## 5. 動きの決まり（GSAP）

- GSAP 公式スキル（`.claude/skills/`）に従う：ScrollTrigger はタイムラインにだけ付ける、上から順に作る、くり返す動きは画面にある間だけ、動きを減らす設定は `gsap.matchMedia`。
- 場面の動きはスクロール（scrub）で進む。1コマ＝スクロールで約1.1画面分。
- **各コマの動きは、そのコマの頭から 0.75 までに終える**（ページ送りは 0.78 で止まる、`BEAT_REST`）。止まった所で、主役の入れ替わりや枝の描き込みが途中にならないように。カメラは `power2.inOut` で減速して落ち着く。二つのコマにまたがるのは、空・水面の色のゆっくりした移り変わりだけ（止まった所では途中の色で落ち着いて見える）。
- **朗読するように**（11/20 23:14 渡辺さん、22:43「文字の数に合わせて一コマの長さを」）：文は一字ずつ朗読の速さ（一字 0.18 秒、読点 +0.35 秒、句点 +0.6 秒）で現れる。区切りへ運ぶ秒数は、その文を読む時間から決める（`readingTimes`・`beatSeconds`、最短 3.2 秒）。スクロールの量は秒数の平方根で縮める（0.9〜1.6 × 110svh、`beatWeights`。23:59「スクロールの距離が長い」）。自動で運ぶときは時間で進むので、字は朗読の速さどおり。場面のタイムラインはコマの番号で組み、スクロールとは重みでつなぐ（`beatWeights`・`beatToProgress`）。どの満月の場面も同じ。
- **本編の前は区切りへ運ばない**（23:13）：本の表紙・見開き・場面へ入る空までは指のまま（`freeBefore`）。場面に入ってから、短く払うと次のコマへ朗読の速さで運ぶ。
- 運び方は台形の速さ：はじめに指を離した速さから一定の速さへ、一定の速さで進み（字が読む速さどおりに出る）、おわりになめらかに減速して止まる。
- 区切りへの運びはページ送り（`src/ui/storyPager.ts`）だけが行う：指は 1:1。短く払ったときだけ区切りへ（触れた時間 280ms 未満・距離 140px 未満・速さ 120px/秒超。ゆっくりのスクロールは指のまま、離したら少しの惰性だけ。11/20 22:09 渡辺さん）、強くても最大3つ。運び方は上の台形の速さ。ScrollTrigger の snap や CSS の scroll-snap を足さない（二つが同じスクロールを動かすと、止まる直前にカクつく）。区切りは `storyStops`（表紙・見開き・コマごと・場面の終わり・締めくくり・今夜の情報）。場面を押す・ドット・とばす も同じ動き。
- 縦書きの文の出し入れ・下の点・枠は `MoonStory.tsx` が共通で行う。場面のファイルは絵の動きだけを書く。

## 7. 満月のほかの空と季節のイベント（一覧、11/20 渡辺さん「梅雨や暦で決まるものを条件にリスト化」）

満月の物語と同じ作り（本 → 場面 → 値）で扱える候補を、**何で日付が決まるか（条件）** で分ける。条件によって、値の出し方・確かめ方・「まだ分からない」の見せ方が違うため。

決まり：
- 計算で決まるもの（A・B）は、アプリが毎年計算する（手で書き写さない）。国立天文台の暦要項と照らすテストを付ける。
- 発表・観測で決まるもの（D）は、発表があるまで出さない。速報値と確定値が違うことがあるので、どちらかを添える。出どころ（気象庁）の利用条件を先に確かめる。
- 起きたかを確かめられないもの（F）は「起きた」とは出さず、「見られるかもしれない」と観察の手引きにする。
- 日本の暦と行事なので、日本の季節の絵（ススキ・団子・短冊・紫陽花など）を使ってよい（3章の「混ぜない」は満月の北米の呼び名の決まり）。
- **暦の言葉と気象の言葉を混ぜない**：暦の「入梅」（太陽の黄経 80°）と、気象庁の「梅雨入り」（発表）は別のもの。並べるときは両方を、何で決まるかを添えて出す。

### D. 気象庁の発表・観測で決まる（年ごとに違い、発表までは分からない）

| イベント | 条件 | 注意 |

| 梅雨入り・梅雨明け（四国地方） | 気象庁の発表（速報値。秋に確定値で見直されることがある） | 暦の入梅（A）と並べて違いを見せる。発表がない年・特定しない年もある |

| 春一番 | 気象庁の発表 | 四国地方が発表の対象かを先に確かめる |

### 進め方
- 満月の場面は 6章の順番（近い順）で先に進める。

## 8. 横展開の決まり（11/20 夜の見直しで決まったこと）

場面を一つ足すたびに、次をそのまま守る。迷ったら PR のコメントに書いて止まる。

### 文と書体
- 書体は物語だけの3つ（`public/event/story/fonts/`、どれも OFL）：名前・見出しは Zen Old Mincho の太字（`--font-engrave`）、物語の文はしっぽり明朝（`--font-story`）、欧文は Cormorant Garamond（`--font-latin`、数字はライニング）。システムの書体に頼らない。
- 書体は使う字だけに絞ってある。**文（`tale`・`book`・由来・自然）を足したら `python3 scripts/story-fonts.py <ttf のフォルダ>` を走らせ直し、`styles.css` の `?v=` を一つ上げる**（字が無いと、そこだけ別の書体で出る）。
- 金の字は「金のグラデーションを字の形に切る＋下に溝の影＋上の縁に光」。金の SVG の飾りは `filter={BEVEL}`（`GoldDefs` が物語のページに一つ）。物語の外で使う部品には付けない（定義が無いと消える）。
- 物語の文・ひと言・`book` は毎年使える言葉だけ。その年だけのこと（月食・ブルームーン・最接近）は計算の側で出す。

### 表紙と本棚
- 表紙の絵は場面の世界と同じ描き方（山・森・川は平たい形で、絵本らしさは主役以外で出す。11/20 19:53）。主役と大きな満月を真ん中に、上の二隅に季節の飾り（素材）。絵の四方は革へ溶かす（四角い縁を見せない）。
- 本の背：横は中央揃え、縦は上詰め。月・英語・線・日本語の頭は全冊同じ高さ、紋・日付・山並みは下に固定。日本語の呼び名は7字までは一列、長いものは「〇〇／ムーン」の二列で、語の途中で折らない。全冊の高さを揃える（次の満月はしおりと光で示し、持ち上げない）。
- 細部：金の帯や線は、背や枠の丸い角より内側から（角からはみ出さない）。足したら 3 倍に拡大して角・端・重なりを見る。

### 絵と素材
- 場面ごとに用意するもの：場面（`World`）・窓・表紙の絵（`CoverArt`）・表紙の飾り（`coverCorner`）・背の紋・紙のページの下の絵（`PaperArt`、セピアの一色）・象徴の言葉3つの絵（`SYMBOL_ICONS`）。
- 渡辺さんの素材は `src/design/story/storyAssets.ts` の台帳に載せ、`node scripts/story-assets.ts <満月>` で webp に。版（`STORY_ASSET_VERSION`）を上げると配り直される。
- 素材の画風（立体的・明るい）と場面の背景（平たい・夜）が合わないときは、場面の側で暗く沈めるか、素材の追加を頼む。北米の呼び名に日本の季節（ススキ・団子・桜）を混ぜない。
- 色は `src/design/story/`（`palette.ts`・`parts.tsx`・場面のファイル）だけ。透け色も palette に置く（CSS の `color-mix` で割合を増やさない）。

### 動き
- 動きは小さく、間をおいて（きらめきは同時に一つ二つ、光の帯は数秒に一度）。動きを減らす設定では、くり返す動きを出さない。
- スクロールに合わせる動きは scrub のタイムラインに。CSS のくり返しは `@media (prefers-reduced-motion: no-preference)` の中に。
- **呼吸**（2026-11-22 渡辺さん OK、ビーバームーンで最初に入れた）：止まっている主人公は、数秒に一度、足もとを支点にごくわずかにふくらんで戻る（縦に 1.5% ほど）。くり返す動きに入れるので、動きを減らす設定では出ない。見えていない姿に掛かっていてもよい（出し入れはスクロールの側）。コールドムーンの眠るコガラ（8ページ）も同じ形で。
- **置いたあとの静けさ**（同上）：主人公が何かを終えたページ（枝を置き終えた、など）では、終えたあとの間に、小さな余韻（水の輪がゆっくり広がって消える、など）をくり返す動きで出す。見えるのはそのページの間だけ（scrub の側で出し入れし、出し入れはコマの 0.75 までに終える）。派手にしない（4秒ほどかけて、間をおいて）。
- ページ送りの手触りは、区切りで止まる・跳ね返らない・途中で触れたら止まる、の3つを撮って確かめる（指の操作の再現：軽く・ゆっくり・強く・戻す・ごく小さく・止めてから離す）。

### 見直しと出し方

- テスト：`npx vitest run`（直書きの一覧が増えたら、CSS に理由を書いて `HARDCODE_WRITE=1`）、`python3 e2e/event.py 360` と `390`。

## 絵本の形（2026-11-21、承認C）

場面のある満月は、`FullMoonNameInfo.book` で **絵本の本文（第1層）・物語のあとがき（第2層）・自然と科学（第3層）** を分けて持つ。
本文に由来や生態の説明を入れない。根拠と、事実・伝承・創作の区別は Project の「事実・出典管理シート」、作品ごとの企画・絵コンテ・
変更一覧・実装計画は Project の `claude/満月の物語/` に置く。

- `book.pages`：1ページ＝場面の1コマ。`lines` は順に出す行、`rest` は読み終えてから絵だけを見せる秒。
- `book.afterword`：名前のひみつ（伝承は「とされる」「という説もある」で書く）。
- `book.science`：小見出しつきの節。物語の創作（昼の場面、一日に縮めたことなど）もここで断る。
- `book` を持つ満月では、締めくくり（ひと言をもう一度）を出さない。持たない満月は `tale` のまま（全作品を同時に変えない）。
- `book` を持つ満月では、物語の月を今夜の情報の月へ引き継がない（`ms-flymoon` を使わない）。月は最後のページの絵に残し、物語の区切りの終わりはあとがきの頭。

### 副題（ひと言、`tale.tagline`）（2026-11-21 渡辺さん）

- 副題は、その作品の**本文の繰り返しの一行をそのまま**使う（ビーバームーン「いっぽん。また、いっぽん。」＝3ページ、コールドムーン「ながい、ながい夜。」＝8ページ）。表紙で読んだ言葉に本文でもう一度出会い、読み終えたときに意味が深まる。
- 句読点と字も作品の言葉にする：ビーバームーンは同じ「いっぽん。」を句点で区切ってくり返す（置く、また取りに行く、置く。どの一本も同じ小さな一本。最初の一本の特別さは絵の赤い葉の枝が受け持つ）。くり返しの一行だけをひらがなの「声」にし、ほかの行の「一本」は漢字のまま。コールドムーンは読点で途切れない（ひと続きの長い夜）。
- 教訓・標語・展開の説明を書かない（「ちいさな一本、おおきな安心」「一本の枝から、冬のすみかへ」のような形にしない）。
- 表記は本文と同じ字・同じ句読点にする（副題を変えるときは、本文のその行も同じに変える）。`tagline` には最後の句点を書かない（表紙が「。」を足す）。
- 作品ごとの主題（企画シートの「作品テーマ」）を、副題そのものに書かない。副題は行動や時間を表し、テーマは物語を読み終えて伝わる。

### 層ごとに書いてよいこと（2026-11-21、コールドムーンの承認B 事前レビューから）

- **絵本（第1層）**：場所と年によらない物語。舞台は呼び名の土地（北米）。由来・生態・天文の説明を入れない。
- **あとがき（第2層）**：名前と歴史。出典が一つしかない民族の名前は書かない（「北米で」にとどめる）。表記は照合した出典の形にそろえる。
- **自然と科学（第3層）**：場所と年によらない事実。**その年だけの数値も、特定の場所（高知など）の時刻や高さも書かない**。年によって揺れること（月の通り道など）は「いちばん〜」と言い切らず、「〜しやすい」と書いて、具体の値は今夜の月に任せる。
- **今夜の月**：観測地とその日から計算した値だけ。
- 言葉の目線（2026-11-21 渡辺さん）：絵本の層は主人公から見た言葉にする（ビーバームーン「おうち」「まわりは夕暮れ」）。同じものでも、自然と科学では説明の言葉（「住みか」）を使う。主人公は話さないので、主人公の声に聞こえる言葉（「あっ。」など）は本文に入れない。
- 物語のための創作の動き（夜に月を見る鳥など）は、事実・出典管理シートに C- の行で残し、習性として描かない（その動きをするページを限る）。

### 素材

- 素材は **ID の数と画像の枚数を分けて数える**（目を開けた版・閉じた版、遠・中・近の背景など）。優先度（最優先・次・条件付き）を付けて頼む。
- 検収は素材ごとではなく、**9ページを通したカメラ構図**で行う（主役の大きさ、前景の残り、月明かりの色を重ねたときの読みやすさ）。

## 文の出し方と時間を秒で決める本（2026-11-26、ビーバームーンの第2次品質改善で確定）

場面が `direction`（`StoryScene.direction`）を持つ本は、ページの時間・字の出る時刻・消える時刻・額縁を秒で決める。
持たない本（コールドムーン）は、今までの計算（行の数・`rest`・`lineAt`・`linePause`）のまま。比べた案と測った値は Project
「ビーバームーン_第2次品質改善計画」「ビーバームーン_段階2の試作結果」。

- **文と出し方を分ける**：本文（`book.pages[].lines`）は文だけ。出し方（演出の単位）と秒は場面の演出
  （`src/design/story/beaverDirection.ts`、型は `direction.ts`）が持つ。単位は「一字ずつ（擬音・反復）」「文節（読点まで）」
  「一文（独立した間のあとの言葉）」。本文の側に `rest` を書かない（時間を二か所で決めない）。
- **ページの区間**＝前の文が消える＋前の絵だけ＋絵が先（`intro`）＋文が出る＋全文が出てから読む（`readHold`）。最後のページは、
  読む → 文が消えきる → （結末の作品名 `book.titleEnd`：文字の無い風景・浮かぶ・残す・消える）→ 額縁 → 絵だけ、まで同じ区間。
  額縁は字が消え終わったことをきっかけに出す（ページの進み具合ではない）。
- **秒を拍へ**：自動で運ぶ速さの形（初め加速・終わり減速・間は一定、`storyPager` の `profile`）と同じ式（`glideFrac`）で写す。
  自動で読むと、字は決めた秒どおりに出る（スクロールに追いつく遅れ `scrub` の約 0.6 秒は、どの字にも同じだけ）。指で払った
  ときは払った速さから運ぶので、少し前後する。重みはどのコマも 1（指で送る量もそろう）。
- **絵が先のページ**（`pictureFirst`）：そのページの「絵が先に見える時間」の頭の拍を、合図として場面に渡す（月の出・初雪）。
- **絵の動きは言葉の合図で**（`cues`）：合図の言葉は本文にあること（`test/data/story-direction.test.ts`）。言葉を本文から
  消しても、動きは残す（例：6ページの見上げる姿は「光の道」のあとに絵だけで）。
- **組版**：字幕は `--size-story`（19〜22px、画面の幅で。作品全体でそろえ、ページごとに縮めない）、しっぽり明朝 500、
  字間 0.08em、行間 1.9。本文の "/" は、列に収まらない画面だけで折る所（意味のまとまり）で、時間には関わらない。
  背の低い画面は、1 意味のまとまりの改行 → 2 字幕の領域（右の余白を詰めて横へ。列は下へ伸ばさない）→ 3 列の間 →
  4 作品全体で同じ大きさに縮める、の順（`fitDirected`）。字が切れないよう自動では 15px まで縮めるが、19px 未満になった
  画面は字幕の箱の `data-small` に残る。そうなる画面が見つかったら、理由と比較の画像を添えて相談する（今は 320〜430px の
  どの画面も縮めていない）。
- **月と字**：月が昇る途中も含めて、字と月の円のすき間を測る（負は不可、10px 以上を目安。11/26 レビューの暫定基準）。
- **ページの冒頭から読める**（11/26）：ドットでページを選んだときと、あとがきから最後のページへ戻ったときは、止まる所へ
  直接ではなく、まずそのページの冒頭（前のページの文が消えて絵だけになった所）へ運び、そこから朗読の速さでページの区間の
  残りを運ぶ（`storyPager` の `entry`）。最後のページなら、結末の文 → 作品名 → 額縁をもう一度見られる。一つ前へ戻る
  （最後のページ以外）は今までどおり、止まった所で文が出そろう。
