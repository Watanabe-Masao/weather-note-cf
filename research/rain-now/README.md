# 雨の見込み（地図とグラフ）の見本

直近の雨を、地図とグラフで見せる見本です（2026-11-18、渡辺さん「地図とグラフで見せたい」）。**データは作ったもの**で、本物の雨ではありません。

- 地図：高知のまわりの雨の強さ（mm/h、気象庁の色の段）。3時間前〜今は実況、今〜1時間先は予測（5分ごと）。予測のこまは点線の枠と「予測」の札
- グラフ（上）：高知の地点の雨の強さ、5分ごと。押す・なぞるとその時刻の地図
- グラフ（下）：1時間ごとの雨の量（mm）。過去はアメダスの実績、この先15時間は「今後の雨」の予測
- 強さ（mm/h）と量（mm）は別のグラフ（要件 R4）。予測は斜線と点線の枠（色だけに頼らない）
- 一文は決まった形だけで作る（理由は言わない）

本番では、気象庁の「雨雲の動き」（高解像度降水ナウキャスト、5分ごと・1時間先まで）と「今後の雨」（降水短時間予報、1時間ごと・15時間先まで）をその場で読みます。保存は要りません（雨雲レーダー・解析雨量の保存は振り返り用）。地点の値は画像の色から読み取ります。出典：気象庁ホームページ（加工したものは「加工して作成」）。

npx vite build --config research/rain-now/vite.config.ts
