# 雨雲レーダーの下調べ（RD-01）

雨雲レーダー（高解像度降水ナウキャストなど）を Weather Note に入れられるかの下調べです。作るのではなく「使ってよいか・どう取れるか・どれくらいの量か」を書きます。
予想天気図は #249 でアプリに入り、R2 への保存も済んでいるため、ここでは調べていません。

調べた日：2026-11-17。コード・ワークフローは変えていません。

**結論から：robots.txt を確かめられなかったので、レーダーの画像・一覧（www.jma.go.jp/bosai/ の下）は今回一度も読んでいません。** 置き場所・大きさの数字は、すでにリポジトリにある記録（#249 の WX-03）と、計算と、仮定によるものです。

## 1. 利用規約（気象庁ホームページについて）

### 確かめたこと
- 権利表記がない限り「公共データ利用規約（第1.0版）」に準拠した条件で利用できる。複製・保存・加工について個別の禁止は書かれていない（公共データ利用規約に従う）。
- 出典の書き方：「出典：気象庁ホームページ（当該ページの URL）」、図は「「図・写真等の名称」（気象庁ホームページより）」。
- 加工した場合（切り抜き・縮小・タイルの組み合わせを含むと考えられる）：出典とは別に加工したことを書く。例「気象庁「図・写真等の名称」（当該ページの URL）を加工して作成」。国が作ったように見せてはいけない。
- 個別の法令の制約として、気象業務法第17条（予報業務の許可）・第23条（警報の制限）に注意、とある。
- 予報・警報などの情報は「常に最新の情報を使う」「発表時刻を確かめる」よう呼びかけている。
- このページには、防災情報のページ（/bosai/）を機械で取りに行くこと・アクセスの頻度・サーバーの負荷についての注意書きは **書かれていない**。
- e-Gov データポータルでは、ナウキャスト（https://www.jma.go.jp/bosai/nowc/）が気象庁のデータとして登録されている（同じ登録の「今後の雨」は「政府標準利用規約（第2.0版）」と表示）。

出どころ：

- https://data.e-gov.go.jp/data/en/dataset/mlit_20140919_0745/resource/a6908863-5726-4e71-bbd7-25f93307dde8

- e-Gov の表示（政府標準利用規約 第2.0版）と、気象庁のページの表示（公共データ利用規約 第1.0版）のどちらが正しいか。中身はほぼ同じ（出典の表示で再利用可）と理解しているが、今回は確かめていない。

## 2. robots.txt

### 確かめたこと
- なし。

### 分からなかったこと（つまずき）
- https://www.jma.go.jp/robots.txt を次の方法で読もうとして、**どれも読めなかった**。
  - 作業環境から：気象庁の各ホストへの接続が許されていない（接続を拒否された）。
  - Web の読み取りの道具から：取得に失敗（相手側のエラー。404 か 403 かは分からない）。
  - 過去の写し（Web アーカイブ）から：そのサイト自体が使えなかった。
- 以前の調べでは GitHub Actions で気象庁に届いたが、今回の指示ではワークフローの追加ができない。
- **このため「禁止されていない」とも「禁止されている」とも言えない。** 指示どおり、レーダーの画像・一覧は取りに行っていない。

## 3. 雨雲レーダー

### 確かめたこと（すでにある記録から。今回は読み直していない）
#249 の WX-03（2026-11-17、Actions で気象庁の一覧 `targetTimes` を読んだ結果）より：
- 「雨雲の動き」（ナウキャスト）は **5分ごと**。降水の強さ（`hrpns`＝高解像度降水ナウキャスト）、雷・竜巻（N3：`liden`・`thns`・`trns`）。
- 気象庁の一覧に残るのは **約3時間分**。それより前は一覧から外れる。
- 「今後の雨」（解析雨量・降水短時間予報 `rasrf`）は 30分ごと、約12時間前〜15時間先。
- どれも **256px の地図タイル**で、1枚の画像ではない。
- 一覧の置き場所：`www.jma.go.jp/bosai/jmatile/data/nowc/targetTimes_N1.json`（実況）・`_N2`（予測）・`_N3`（雷・竜巻）、`…/jmatile/data/rasrf/targetTimes.json`。

ほかの出どころから：
- 高解像度降水ナウキャストは 2014年8月に始まった（それまでの降水ナウキャストは 2004年夏から、1km、1時間先まで）。
- 「今後の雨」は 1km 四方の解析と15時間先までの予報（7時間先以降は5km）。
- 気象庁のナウキャストのタイルを取る仕組みを作った第三者のライブラリがある（地点と拡大の段階からタイル番号を出す）。気象庁の公式の説明ではない。

出どころ：
- https://github.com/Watanabe-Masao/weather-note-cf/issues/249 （WX-03 のコメント）
- https://www.jma.go.jp/jma/en/Activities/qmws_2018/Presentation/3.1/High-resolution%20Precipitation%20Nowcasts.pdf
- https://data.e-gov.go.jp/data/en/dataset/mlit_20140919_0745/resource/6adcdec0-d9c8-46b0-8512-1c94291ce9ea
- https://github.com/tak0kada/jma

### 計算で分かること（取りに行かずに出せるもの）
高知市（北緯33.56度・東経133.53度）が入るタイル（地図タイルの一般的な番号の付け方で計算）：

| 拡大の段階 | 高知市のタイル（x, y） | 1枚の幅（東西） |
|---|---|---|
| 7 | 111, 51 | 約260km |
| 8 | 222, 102 | 約130km |
| 9 | 445, 205 | 約65km |
| 10 | 891, 410 | 約33km |

- 段階8では高知市がタイルの東の端（96%）にあるので、高知市を真ん中にするには横2枚以上がいる。
- 「高知のまわり」を 3×3 枚にすると、段階8で約390km 四方（四国全体）、段階9で約195km 四方（高知県全体くらい）、段階10で約100km 四方。
- 気象庁のタイルがこの番号の付け方か、どの段階まであるかは **確かめていない**（第三者のライブラリでは段階8の例がある）。

### 分からなかったこと
- タイル1枚の大きさ（KB）、形式（PNG と思われるが未確認）、あるのはどの段階までか：画像を読んでいないので **確かめられなかった**。
- 一覧（targetTimes）とタイルの置き場所が robots.txt で禁止されていないか：**確かめられなかった**。
- 3時間より前を気象庁から取り直せるか：一覧に無いだけでファイルが残っているかは **確かめていない**。#249 の記録どおりなら、後から取り直せない前提で考えるのが安全（推測）。
- 「表示だけ」と「保存する」の両方について、/bosai/ の注意書きから見て問題がないか：注意書きを読んでいないので **確かめられなかった**。規約（1.）だけから見れば、出典と加工の表示をすれば表示も保存も認められる書き方（推測）。

## 4. 量と費用の見積もり（仮定）

タイル1枚の大きさが分からないので、**1枚 5KB／20KB／50KB の3通りの仮定**で出します（雨の少ない時は小さく、強い雨が広がる時は大きいと思われる。推測）。条件：降水の強さ（`hrpns`）の実況だけ、1時間ごと（1日24回）、3×3＝9枚。

| 1枚の仮定 | 1日 | 1か月 | 1年 | 10年 |
|---|---|---|---|---|
| 5KB | 1.1MB | 32MB | 0.39GB | 3.9GB |
| 20KB | 4.3MB | 130MB | 1.6GB | 16GB |
| 50KB | 11MB | 320MB | 3.9GB | 39GB |

- 書き込み（R2 の Class A）：216回／日 ＝ 約6,500回／月。

### R2 の料金
- Standard：保存 $0.015／GB・月、Class A（書き込み）$4.50／100万回、Class B（読み出し）$0.36／100万回、外への転送は無料。
- 毎月の無料分：保存 10GB・月、Class A 100万回、Class B 1,000万回。

出どころ：
- https://developers.cloudflare.com/r2/pricing/

### 費用の目安（計算）
- 書き込みは月 約6,500回で、無料分（100万回）の1%未満。
- 保存は、今の予報・電文・天気図の保存（すでに R2 にある）と合わせて 10GB を超えるまでは無料。20KB の仮定だと、レーダーだけで10GB に届くのは約6年後。
- 10GB を超えた分は 1GB あたり月 $0.015。20KB の仮定で10年分（16GB）を持つと、無料分を引いて月 約 $0.09（約14円）。50KB の仮定で10年分（39GB）なら月 約 $0.44。
- R2 の料金は Workers Paid（月 $5）とは別に数えられ、無料分は R2 自体の分（Workers Paid に含まれる分ではない）。どちらにしても、この量では R2 の費用はほぼかからない。

## 5. おすすめ

- **「表示だけ」で始めるのがよい**（推測を含む）。理由：
  1. robots.txt と /bosai/ の注意書きを確かめられていない。表示だけでも気象庁の置き場所を読むことに変わりはないが、保存（定期的にまとめて取りに行く）のほうが負荷も責任も大きい。
  2. 表示は「最新を使う」という気象庁の呼びかけに合う。
  3. 量・費用は保存しても小さい（上の見積もり）ので、保存は後から足しても困らない。ただし **3時間より前は取り直せない前提**なので、保存を始めた日より前の分は無い。
- どちらで始めるにしても、**先に robots.txt と /bosai/ の注意書きを確かめる**必要がある。
