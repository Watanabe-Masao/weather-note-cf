# コールドムーンの素材（原本）

2026-11-22 に受け取り、渡辺さんと検収した原本（透明の PNG）。依頼は `../request/README.md`（v0.3）、検収の記録は Project の `claude/満月の物語/コールドムーン_素材の依頼.md`。
アプリに入れる webp は PR-2 で `node scripts/story-assets.ts cold` から作る（ここはまだ `storyAssets.ts` に載せていない）。
置く位置の目印（足・幹の根元・穴の口など）は `anchors.json`。

取り込むときに直したこと（機械的）：絵の部分が約1%透けていた（透明度の最大が 252 前後）ので不透明にそろえ、縁のやわらかさは比で伸ばした。透明の所の色は捨てた。絵そのものは変えていない。
