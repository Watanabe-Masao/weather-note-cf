# 視程を計算に使う見本（2026-11-21）

画面には使っていない。視程（気象台の視程計、km）から空気の濁り β を見積もり、月の見え方（MA-01・MA-02）がどれだけ変わるかを見るための計算。`python3 vis_beta.py`。

- 式：σ = 3.912 / V（Koschmieder）→ 分子の分（0.0116 /km）を引いてちりの分 → 高さ 1.2 km まで同じ濃さとみて τ550 → β = τ550 × 0.55^1.3。
- 結果（月の高さ 10° の色と明るさ）：β 0.05（いま）#ffdea7・0.28、視程 20 km #ffd290・0.16、10 km #ffbb66・0.04、6 km #ffa138・0.01。
- 分かったこと：
  - 視程は上限が 20 km なので、**澄んだ日は見分けられない**。20 km でも β 約 0.10 になり、いまの固定（0.05）や CAMS の AOD（11/18〜26 で 0.03〜0.2、β で 0.01〜0.09）より濁った側に出る。
  - **霞んだ日（20 km 未満）には差が大きく出る**（10 km で低い月の明るさは 1/7）。雨や霧の水滴もちりとして数えてしまう（雨の時間は月が見えないので、実際には問題になりにくい）。
  - 使い方の案：β はふだん CAMS の AOD から出し、視程が 20 km 未満の時間だけ視程から出した値と比べて大きい方を使う（地上近くの霞を拾う）。決めるのは実際の空と見比べてから。
- 仮定：ちりの高さ 1.2 km、α 1.3、目のコントラスト 2%。
