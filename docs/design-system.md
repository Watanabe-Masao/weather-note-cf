# Weather Note デザインシステム

見た目と操作のルール。値は `src/design/tokens.ts` が唯一の出どころで、`applyTokens()` が CSS 変数（`--surface-*` など）として配ります。
`styles.css` に生の色・時間・z-index を書かないこと。

## 1. 原則

- **比較が主役。** 対象日と比較日は、いつも同じ並びにする（左／上が対象日、右／下が比較日）。どちらかを強く見せるときは、比較日を少し控えめにする（不透明度 0.7〜0.82）。
- **シンプルに、でも豊かに。** 装飾は足さない。奥行きは、ごく薄いグラデーション、柔らかい影、アクセントのにじみ（中央の帯）だけで出す。
- **1つの意味には1つの見た目。** 色、線種、閉じ方、単位の書き方は全画面で同じにする。

## 2. 色

| 役割 | トークン | 使う場所 |
| --- | --- | --- |
| 面 | `surface.page / base / raised / overlay / inset` | 背景 → カード → 浮いたシート → 入力欄やへこんだ面 |
| 文字 | `ink.primary / secondary / tertiary / disabled / onAccent` | 本文 → 補足 → ラベル・単位 → 欠測 → アクセント上の文字 |
| 線 | `line.soft / strong / focus` | 区切り → 枠 → フォーカス |
| アクセント | `accent.base / strong / wash / glow` | 選択中（チップ・帯・カレンダー）だけ |

**データの色（DATA）は 1色につき意味が1つ。**

| 色 | 意味 |
| --- | --- |
| `hot` | 最高（気温・気圧の最高も） |
| `cold` | 最低 |
| `mean` | 平均・気温（参考線） |
| `rain` / `snow` | 降水量 / 降雪 |
| `sun` | 日差し（日射量・日照） |
| `humidity` / `wind` / `pressure` | 湿度 / 風速 / 気圧 |
| `feel` | 日なた温度・日かげ温度 |

- 対象日と比較日は**色で分けない**。線は実線（対象日）と破線（比較日）、棒は塗り（対象日）と枠線（比較日）で分ける。
- **線の種類は「どちらの日か」だけを表す。** 予報かどうかで線の種類は変えない。予報の日や時間は、グラフの背景を網かけにし、その上端に「予報」と書いて示す。
- 肌感の5段階は `FEEL_LEVELS`、時間区分の5本線は `BAND_LINES` を使う。
- 土曜は `day.saturday`、日曜・祝日は `day.holiday`。日付と曜日にだけ使う。
- 状態の色：予報 `status.forecast`、暫定 `status.provisional`、エラー `status.error`。

## 3. 数値・単位・日付（`src/design/format.ts`）

- 単位は数値の後ろに小さく付ける（`.unit`）：℃、mm、cm、%、m/s、hPa、MJ/㎡、h。
- 小数点以下の桁数は単位で決まる：℃ 1、mm 1、cm 1、% 0、m/s 1、hPa 0、MJ/㎡ 1（1時間ごとの値だけ 2）、h 1。1時間ごとの日照は「40分」と書く。
- 差は `signedDiff`：「+1.2」「−0.4」「±0」。マイナスは全角の「−」。どちらかの値がなければ空にする。
- 欠測は「—」（`ink.disabled`）。
- 日付は0で埋めない：「11/9（月）」。年を付けるのは、比較日が対象日と別の年のときと、見出しだけ。
- 軸の目盛りは `niceTicks` を使って、切りのいい値にする（10 / 15 / 20）。単位は軸の上に書く。

## 4. 部品（`src/ui/kit.tsx`）

| 部品 | 用途 | ルール |
| --- | --- | --- |
| `Chip` | 項目や線を選ぶ | オフは控えめ、オンは `--chip-tone`（線の色やアクセント）で光らせる。`sm` は見出しの中で使う |
| `Segmented` | 表示の切り替え（2〜3択） | 選んだ方を一段持ち上げて明るくする。選んだ方をもう一度タップしたときの動き（`onReselect`）は、日なた／日かげの切り替えだけに使う |
| `IconButton` | ⚙ ⤢ × | 押せる範囲は 36px（`sm` は 32px） |
| `Badge` | 今日／昨日／明日、予報／暫定／実績 | 今日などは塗り、状態は枠線 |
| `DayLabel` | 日付 | 曜日に土曜・祝日の色を付ける |
| `Num` | 数値＋単位 | 丸みのある等幅数字 |

アイコンは `src/ui/icons.tsx` の SVG だけを使う（文字の記号は使わない）。

## 5. 閉じ方・戻り方

**オーバーレイのシート（肌感マップ・似た日・カレンダー・設定）はすべて同じ閉じ方にする。**

1. 上端のグラバー（つまみ）を下へドラッグ（速く弾いても閉じる）
2. 見出しの右端の ×
3. 背景（暗くなった部分）をタップ
4. Esc キー

- 下部の「閉じる」ボタンは置かない。
- 選ぶシート（似た日・カレンダー）は、選んだら閉じる。
- 「‹ 日別」は**シートの中で前の画面に戻る**ためのもの。閉じるのには使わない。
- グラフのシートは閉じない。高さを変えるだけ（最小／中／最大）。最大まで上げたときは項目チップの下で止まる。

## 6. 重なり順（`LAYER`）

| 値 | 層 |
| --- | --- |
| 0 | ページ |
| 5 | 中央の帯 |
| 6 | 固定表示された1行サマリー |
| 9 | グラフシートの背景（暗くなる部分） |
| 10 | グラフシート |
| 30 / 31 | オーバーレイの背景 / オーバーレイのシート |
| 40 | ポップオーバー（週送りバッジ） |

- 新しい層を作らず、この表のどれかに入れる。
- オーバーレイはいつもグラフシートより上に出る。オーバーレイを2枚重ねて出さない。

## 7. 動き（`MOTION`）

| トークン | 時間 | 用途 |
| --- | --- | --- |
| `quick` | 140ms | 押したときの反応（縮む、色が変わる） |
| `base` | 220ms | 切り替え、帯の移動、ピンの出入り |
| `enter` / `exit` | 380 / 260ms | オーバーレイの開閉（閉じる方を短く） |
| `settleMin–Max` | 220–460ms | 指を離した後にシートが止まるまで（距離と速度で決める） |

- イージング：`standard` は一般の動き、`sheet`（iOS のシートに近い減速）はシート、`exit` は閉じるとき。
- シートの物理：速度は直近 100ms から測る。弾く速さが 0.4px/ms を超えたら、少なくとも1段は動かす。端では輪ゴムのように抵抗をかけ、指を離すと戻す。
- グラバーは指が触れている間、幅を広げて明るくし、触れていることを伝える。
- `prefers-reduced-motion` のときはアニメーションを止める。

## 8. 効果

- 背景を暗くする：グラフシート `effect.scrim`＋ぼかし 2px、オーバーレイ `effect.backdrop`＋ぼかし 4px。
- 浮いたものの影：カード `shadow.card` → シート `shadow.sheet` → オーバーレイ `shadow.overlay`。固定表示の行は `shadow.pinned` と `effect.blur` で、すりガラスのように見せる。
- 面の上端にだけ、ごく薄く明るいグラデーションを入れる（光が上から当たっているように見せる）。
- 中央の帯：連動中は実線＋にじみ、個別のときは破線でにじみなし。

## 9. 言葉

- 対象日／比較日、日別／時間帯、日差し（日射量）と日照、日なた温度／日かげ温度、寒暖差（最高−最低）。
- 推定値には「目安」、予報には「予報」、まだ確定していない実績には「暫定」と付ける。
- ボタンの文字は動詞か名詞の短い形にする（「表に集中」「選択中の月へ」）。「〜します」は付けない。
