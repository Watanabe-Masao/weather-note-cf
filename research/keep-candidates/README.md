## 1. 今後の雨（降水短時間予報）と解析雨量

### 確かめたこと（KC-01）
一覧：`https://www.jma.go.jp/bosai/jmatile/data/rasrf/targetTimes.json`
- HTTP 200、JSON 17,012 バイト、`cache-control: max-age=60`。115行。
- 基準時刻（basetime）は 75個、2026-11-17 02:00〜14:20（UTC）＝ **約12時間分**。
- `member` は `none` と `immed`（速報と思われる。推測）。
- 要素：`rasrf`（1時間雨量）、`rasrf03h`（3時間）、`rasrf24h`（24時間）、それぞれ `_point`・`_nd`。ほかに `slmcs`（線状降水帯）、`sjfcstmap`（線状降水帯の予測）も同じ一覧にある。
- 予報の行の例：基準 14:00（`none`）に対象 2026-11-18 03:00・04:00・05:00 …（1時間ごと、15時間先まで）。
タイル：`…/rasrf/{basetime}/{member}/{validtime}/surf/{要素}/{段階}/{x}/{y}.png`
- 高知市のタイル（段階8 の 222,102）は PNG 256×256。
- 大きさ（ほぼ雨なし）：`rasrf` 526 バイト、`rasrf03h` 423、`rasrf24h` 275、`_point`・`_nd` は 334（何も無い所の共通の画像と思われる。推測）。一覧のいちばん古い（12時間前）の `rasrf` は 1,361 バイト。
- **24時間前（一覧に無い）のタイルは HTTP 404**。ナウキャスト（#274、6時間前でも読めた）と違い、解析雨量は一覧から外れると消える。

## 4. 天気分布予報と暑さ指数（熱中症警戒アラート）

### 天気分布予報

#### 確かめたこと

- KC-03：Actions の中でブラウザ（Playwright、e2e の検査と同じ 1.49.1）に時系列のページ（高知）を開かせ、読みに行った先を記録した。
  - このページの名前は **「地域時系列予報」**（天気分布予報の地図ではない）。`#area_type=class20s&area_code=3920100`（高知市）で開くと、高知県（`offices` 390000）に切り替わった。
  - 読んだデータ：`https://www.jma.go.jp/bosai/jmatile/data/wdist/VPFD/{一次細分}.json` の3つ（**390010 中部**・390020 東部・390030 西部）。各 **約2KB**（2,042〜2,054 バイト）、`last-modified` 2026-11-17 11:41 UTC（画面の「高知地方気象台 2026年11月17日20時発表」）、`cache-control: max-age=300`。区域の番号ごとに1つの URL で、日時が入っていない → **最新の発表で上書きされる**。

#### 後から取り直せるか
- 地域時系列予報：同じ URL を上書きするので、**次の発表で前の分は取れなくなる**。
- 天気分布予報：#249 WX-03 で「最新の発表だけ」。
