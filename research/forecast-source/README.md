## 7. 利用の条件（気象業務法・利用規約）

### 確かめたこと
- 予報業務の許可（第17条）が要るのは、観測資料などをもとに **独自に** 予想した結果を **他者に発表する** 業務。気象庁の発表した予報を **解説するだけ** なら許可は要らない（気象庁 Q&A）。https://www.jma.go.jp/jma/kishou/minkan/q_a_m.html
- 数値予報の格子点値を **そのまま** 見せるのは許可不要だが、**空間内挿・高度補正などの加工** をしたり、**特定の地点の予報として** 見せたりすると独自の予報とみなされ、許可が要る（同 Q&A）。予測の方法（自動の計算でも）は問わない。
- 「予報」は観測の成果に基づく現象の予想の **発表**、「予報業務」は予報を **反復・継続** して行うこと（気象庁「外国法人等が行う予報業務の取扱い」の注）。https://www.jma.go.jp/jma/kishou/minkan/tekiyou.pdf
- 気象庁のホームページの値を使うときは出典を書き、加工したら加工したと書く（利用規約、上記）。

### 判断の材料（推測。法律の判断ではない）
- **気象庁の予報の値をそのまま見せる**：出典を書けば、利用規約の上でも、予報業務の上でも問題は少ないと思われる。
- **Open-Meteo の1時間ごとの線を気象庁の最高・最低に合わせて調整して見せる**：Q&A の「加工して特定の地点の予報として見せる」にあたる。**他の人に見せる（発表する）なら許可が要る側** と読める。**渡辺さん一人が使う（2026-11 の判断の「個人利用」）なら「発表」にあたらない** と読めるが、Q&A に個人利用を直接扱う問いは無く、**確かめられなかった**。いまの Open-Meteo の値（地点の予報として見せている）も同じ扱いになると思われる。
- アプリを他の人に見せる・公開するときは、気象庁（情報利用推進課）に聞くのが確実。

## 判断の材料（まとめ）
- 気象庁で「正」にできるのは：明日 24時までの 3時間ごとの気温・天気・風（区域）、明日までの 6時間ごとの降水確率、7日先までの日ごとの天気・降水確率・最高・最低（予測範囲つき）。8〜14日先は 5日間平均の気温だけ。

## 2. 予報業務の許可の線

### 確かめたこと
- 「予報」は時と場所を特定し、観測の成果をもとに科学的方法で予想して、利用者に提供すること。「業務」は反復・継続して行うこと。https://www.jma.go.jp/jma/kishou/minkan/q_a_m.html
- **許可が要らない**（気象の手引き p.1）。https://www.jma.go.jp/jma/kishou/minkan/tebiki/kishou_tebiki.pdf
  - 予想する人が、学校・会社・家庭などでの利用に留め、他者に提供しないとき。
  - 気象庁の予報を解説したり、そのまま伝達したりするとき。
- 数値予報の格子点値（GPV）をそのまま見せるのは許可不要。空間内挿・高度補正などをして**特定の地点の予報として見せる**と独自の予報とみなされ、許可が要る（Q&A）。
- 複数のモデルの結果について「実現性が高い／低い」などを論評すると、独自の予報と受け取られるおそれがある（Q&A）。
- 予想を第三者に反復・継続して発表すれば、手段や営利・非営利を問わず許可の対象（気象庁の説明資料 2014）。

### 判断の材料
- **気象庁の値をそのまま出典つきで出す**（札・ⓘ・◇）：「そのまま伝達」の側。
- **①②**：気象庁の値から選ぶ・引くだけで、新しく予想はしていない。ただ、①を「日の降水確率」として出すと、気象庁に無い予報の要素に見える。だから1の案のとおり「Weather Note の計算」と書くのがよい（推測）。
- **Open-Meteo の補完**：Open-Meteo の値は、モデルを特定の地点に合わせた値。これを地点の予報として出すのは、Q&A の「特定の地点の予報として表示」にあたりうる。
  - **渡辺さん一人や家庭で使う間**は、手引きの「家庭等での利用に留め、他者への提供を行わない」にあたり、許可は要らないと読める（確かめられた範囲）。
  - **他の人に公開する場合**、補完の Open-Meteo の値が「外国の事業者の予報をそのまま伝える」と「特定の地点の予報として見せる」のどちらにあたるかは、**確かめられなかった**。
- A・B・C（ばらつき）は「当たりやすさ」の論評にあたりうる（Q&A の論評の問い）。公開するなら言い方に気をつける（推測）。

### 気象庁に聞くなら（文案。宛先：気象庁 情報基盤部 情報利用推進課）
> 個人で作っている天気のアプリ（無料・広告なし）についてお伺いします。
> 1. 気象庁の府県天気予報・府県週間天気予報（防災情報XML）の値を、そのまま、発表の種類・時刻・地点を添えて表示しています。この表示は「そのまま伝達」として予報業務の許可は不要と考えてよいでしょうか。
> 2. 気象庁の6時間降水確率のうち最も高い値を、その日の降水確率として、「気象庁の6時間降水確率からアプリが選んだ値」と明記して表示することは、独自の予報にあたりますか。
> 3. 気象庁の予報が無い日（8日先以降など）は、海外の事業者（Open-Meteo）が提供する地点の予報値を、出どころを明記して、加工せずに表示しています。これを不特定の人が見られる形で公開する場合、予報業務の許可は必要になりますか。家族だけが使う場合はどうでしょうか。

  - 気象庁の1日前は「日中の最高（9〜18時）・朝の最低（0〜9時）」、実際は 0〜24時。
- 調べたのは高知の1地点、気温の最高・最低だけ。室戸岬・清水、天気・降水確率は比べていない。
- 8日先から先（Open-Meteo だけの日）の当たり具合は、気象庁の値が無いので比べられない。Previous Runs の previous_day は 7 まで。

# FS-03　予報の誤差の範囲を統計で求める（2026-11-23）

## 材料と方法
- 予報：気象庁の府県・週間天気予報（高知 74182）。shiromatz の記録から、予報した日（D−n）の値のある中でいちばん遅い発表（FS-01 と同じ）。1〜7日前の最高・最低。週間予報の「予測範囲」（Upper・Lower）も読んだ。
- 実績：高知 47893 の日最高・日最低（気象庁 過去の気象データ）。
  - Actions で 1 回だけ取り出し、`fs03_obs_47893.csv` に置いた（1,004 日、2024-02-01〜2026-10-31）。
  - そのあとの計算は手元でした（`fs03.py`）。ワークフローは消した。
- 誤差 e＝予報−実績（℃）。範囲は「実績＝予報−e」なので、[予報−e の 90%点, 予報−e の 10%点]。
- 時間で分けた確かめ：
  - 古い期間 2024-02〜2025-10（21か月）で範囲を作り、新しい期間 2025-11〜2026-10（12か月、四季がそろう）で確かめた。
  - 逆の向き（新しい期間で作り、古い期間で確かめる）でも確かめた。
- **Open-Meteo はしていない**：FS-02 の6はログに集計だけを出し、日ごとの値を残していない。新しく読まない指示なので、日ごとの誤差が作れない（→「まだ判断できない」）。

## 4. 傾向（上振れ・下振れ）

- 全期間の誤差の平均は、**最低の1日前（+0.27℃、95% の幅 ±0.07）を除いて、どれも ±0.1℃ 以下で、0 と区別できない**（日ごとの誤差のつながりは見ていないので、幅は実際より狭めの見積もり）。最低の1日前は、1 の定義の違いによるものと思われる。
- 最近（〜2026-10-31）：
  - 最近90日の最低は +0.2〜+0.5℃（予報が高め）で、全期間より大きい。ただし幅が ±0.2〜0.4 あり、はっきりしない。
  - 最近30日は幅が ±0.4〜1.0 で、何も言えない。
- **最近の平均を引いて直すと、かえって外れる**（新しい期間の絶対値の平均。例：最高 7日前 そのまま 1.77 → 30日の平均を引く 1.90、90日 1.81）。古い期間の季節の平均を引いても、よくならない。
- 結論：**上振れ・下振れは「傾向として出す」ほどの大きさではない**。出すなら、最低の1日前の「実際は予報より少し低くなりやすい（夜の冷え込み）」だけ。

## おすすめの求め方（判断の材料）

- **何日前ごとの経験分位（誤差の 10%・90%）**。季節は **前後2か月（5か月の窓）を合わせる**。
  - 当たり具合：新しい期間で 77〜78%、逆の向きで 80〜81%。
  - 広さ：平均で最高 4.2℃、最低 3.5℃（1日前 約3℃、7日前 約5℃）。
  - 季節で分けないのと、ほぼ同じ成績。最低で季節のむらが小さく、スコアがいちばんよい。
- 平均±σ（①）は、最高で入る割合が少し高い（80.7%）が、広さも広い。分布の偏り（最低1日前の右の裾、最高の右の裾）を表せない。経験分位はこの偏りをそのまま映す。
- 月だけで分けるのは、データが足りず狭すぎる（使わない）。
- 範囲は、作る日までの**全部の過去**から作るのがよい（推測：今回の確かめは 21 か月で作った値。データが増えれば安定する）。2026年のように外れやすい年は、少し狭く出る。
