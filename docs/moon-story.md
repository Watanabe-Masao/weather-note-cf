# 満月の物語（絵本）の作り方と品質の決まり

2026-11-20 渡辺さんの OK（ビーバームーンの第3版、#386）を基準の品質とし、ほかの満月へ横展開するための決まり。
画面は `src/ui/MoonStory.tsx`、絵と動きは `src/design/story/`、文は `shared/fullMoonNames.ts` の `tale`。

## 1. 体験の流れ（どの満月も同じ）

「本を開く → 物語に入る → 満月を見る → 天文情報を知る」を、途切れない一つの動きにする（16:45 のレビュー）。

| 段 | 見せ方 | 作り |
|---|---|---|
| 表紙 | 紺の革・金の飾り枠・満月のメダル。主役は英語の名前を細い欧文の斜体、日本語は小さく字間を広く | `Book.tsx`（共通） |
| 見開き | 表紙は背でつながったまま起き上がり、裏が左へ倒れる。右のページに「窓」とひと言 | 共通。窓の絵は場面ごと（`Window`） |
| 物語に入る | 窓の中へ寄り、窓の空の色で画面を覆ってから、場面が溶けて現れる（紙一色の画面をはさまない） | 共通。空の色は場面ごと（`sky`） |
| 場面 | 一枚の続いた世界を、物語の一文ごとに一コマ。文は明朝の縦書きで空に、一字ずつにじみから浮かぶ | 場面ごと（`World` と `build`） |
| 締めくくり | ひと言をもう一度（読点で改行） | 共通 |
| 天文情報 | 物語の満月が「満月になる時刻」のカードの月へ移る。その夜の空のカード（通り道・出・高い・入り） | 共通（`EventInfo.tsx`） |
| 知識 | 名前の由来・自然との関係を、生成りの紙のページで | 共通 |

物語の演出と天文の値は分ける：場面の絵は文化的なイメージで自由に描き、時刻・通り道・月の出入りは計算の結果だけを出す。

## 2. 場面を一つ足す手順

1. `shared/fullMoonNames.ts` にその呼び名の `tale`（ひと言と文）があることを確かめる。無ければ先に文を用意する（渡辺さんの確認）。
2. `src/design/story/<名前>World.tsx` を作る（`BeaverWorld.tsx` を見本に）。書き出すものは5つ：
   - `<NAME>_BEATS`：文の数（一文が一コマ）。
   - `<Name>World`：場面の SVG。部品は `parts.tsx`（`StoryMoon`・`MoonDefs`・`stars`・`pine`・`SkyGradient`・`rand`）を使う。
   - `<Name>Window`：本のページの窓の絵（最初のコマを小さくしたもの）。
   - `<NAME>_SKY`：最初のコマの空の色（`cssSky(...)`）。窓の空と、場面の最初の空が同じ色であること。
   - `build<Name>Scene(gsap, root, tl, loops)`：コマの動き（`tl` は 0〜コマ数の拍）と、くり返す動き（落ち葉・雪など）。
3. `src/design/story/scenes.ts` の `STORY_SCENES` に呼び名で足す（ブルームーンは「ブルームーン」）。
4. `test/data/story-scenes.test.ts` が通ることを確かめる（コマ数＝文の数、月の目印が一つ、絵に文字なし、窓と空の色）。
5. `npm run build` のあと `python3 scripts/story-capture.py <その満月の日> <出力フォルダ>` で一覧（strip.png）と動画を撮り、見直す（4章）。
6. PR に一覧と動画の所見を書き、渡辺さんの OK のあとにマージ。

## 3. 絵の決まり

- **一枚の続いた世界**：場面を切り替えない。カメラ（`.<p>-camera` の拡大と移動）で寄り・引きをして、一文ごとに見どころを変える。
- **層に分ける**：空（時間ごとに重ねる）・星・満月・遠景・中景・主役・水面・手前・舞うもの（葉・雪・花びら）・枠。それぞれを独立して動かす。
- **主役を見せる**：主役（動物・人・花）が名前の由来を伝えるコマでは、主役に寄り、何をしているかが分かる動き（枝を置く、など）を入れる。
- **満月は一つ**：`StoryMoon` で描く（今夜の情報の月へ引き継ぐ目印が付く）。名前の文のコマで昇り、その前に地平の向こうが明るくなる。昇るにつれて周りを少し沈め、水面があれば月の道を伸ばす。
- **夕暮れから夜は時間差で**：空・水面・木・星を少しずつずらし、二つの文にまたがって変える。
- **文字を絵に描き込まない**（文は画面の側で重ねる）。
- **色はデザインの層だけ**（`src/design/story/`）。画面のコード（`src/ui/`）に色を書かない。月の色は `STORY_MOON` で共通。
- **カメラの決まり**：大事なもの（主役・月・文）が、縦書きの文の場所（右上）と重ならない。下の点（今のコマ）にもかぶせない。
- **科学と文化を混ぜない**：名前は主に北米の季節に基づく呼び名。日本の季節の行事と混ぜない。月の色を名前に合わせて塗らない（ピンクムーンの月はピンクにしない、など）。その年だけのこと（月食など）は場面に入れず、天文情報の側で計算から出す。

## 4. 見直しの仕方（品質の基準）

`scripts/story-capture.py` の一覧と動画で、次を一つずつ確かめる。ビーバームーンの第3版（#386）が基準。

- 表紙：名前が読める。英語の名前が主役で、カタカナが大きく出ていない。
- 開き方：表紙と裏が背でつながったまま。左右のページは同じ大きさ。
- 入り方：窓 → 空の色 → 場面の最初のコマが、色の段差なしにつながる。
- コマごと：その文の見どころが画面にある（文と絵が合っている）。主役のコマで主役が小さすぎない。
- 文：どのコマでも読める（夕焼けの明るい空でも）。月・主役と重ならない。
- 月：名前の文のコマで昇る。物語の終わりから、カードの月へ途切れずに移る。
- 動きを減らす設定：場面は一枚の絵（月が昇ったあと）と、文を全部並べて見せる。
- 360px と 390px で、はみ出し・切れがない（`e2e/event.py` も通す）。

## 5. 動きの決まり（GSAP）

- GSAP 公式スキル（`.claude/skills/`）に従う：ScrollTrigger はタイムラインにだけ付ける、上から順に作る、くり返す動きは画面にある間だけ、動きを減らす設定は `gsap.matchMedia`。
- 場面の動きはスクロール（scrub）で進む。1コマ＝スクロールで約1.1画面分。場面を押すと次のコマへ。
- 縦書きの文の出し入れ・下の点・枠は `MoonStory.tsx` が共通で行う。場面のファイルは絵の動きだけを書く。

## 7. 満月のほかの空のイベント（一覧、11/20 渡辺さん）

満月の物語と同じ作り（本 → 場面 → 天文の値）で、日本の暦と文化の行事、空の現象も扱えるようにする候補。日付はどれも計算で出し、国立天文台の暦要項で確かめる（書き写さない）。日本の行事なので、日本の季節の絵（ススキ・団子・短冊など）を使ってよい（3章の「北米の呼び名と日本の季節を混ぜない」は満月の呼び名の決まり）。

### 7.1 太陽と月の暦・文化の行事

| イベント | 時期・条件 | 出し方（計算） | 物語のモチーフ |
|---|---|---|---|
| 初日の出 | 1月1日 | 高知の日の出の時刻と方位（今の計算） | 新しい年の始まり |
| 旧正月 | 旧暦1月1日 | 旧暦の計算（朔と中気。新しく足す） | 新しい月と新年 |
| 節分・立春 | 2月ごろ（立春の前日が節分） | 太陽の黄経 315° | 冬から春への変わり目 |
| 春分・秋分 | 3月・9月ごろ | 太陽の黄経 0°・180° | 昼と夜の釣り合い |
| 七夕 | 7月7日 | 決まった日 | 星と願い（織姫星・彦星の位置は計算から） |
| 伝統的七夕 | 国立天文台の定義（処暑を含む日かそれより前のいちばん近い朔から7日目） | 旧暦の計算 | 月明かりと星空 |
| 中秋の名月 | 旧暦8月15日（満月と1〜2日ずれる年がある。両方を出す） | 旧暦の計算 | 月見と秋の実り（ススキ・団子） |
| 十三夜 | 旧暦9月13日 | 旧暦の計算 | 栗名月・豆名月 |
| 十日夜 | 旧暦10月10日 | 旧暦の計算 | 収穫への感謝 |
| 冬至 | 12月ごろ | 太陽の黄経 270° | 太陽が再び高くなる節目 |
| 二十四節気 | 年24回 | 太陽の黄経 15° ごと | 四季の細かな変化（毎回は大きく見せず、暦の札として） |
| 八十八夜 | 立春から数えて88日目 | 立春 + 87日 | 新茶と初夏 |

- 旧暦の計算（朔・中気・閏月）は新しく足す。足すときは、数年分を国立天文台の暦要項と照らすテストを付ける。
- 次に近いもの：冬至（2026-12-22）、初日の出（2027-01-01）、節分・立春（2027年2月）。満月の場面づくりと並べるかは、渡辺さんの判断。
- 見出しの絵（docs/event-banner.md の台帳）と、物語の場面の両方が要る。絵の種類が増えるので、満月と同じく文字の無い絵を渡辺さんに頼むか、コードで描くかを先に決める。

### 7.2 空の現象（日付で決まらない、観察の手引き）

| 現象 | 条件 | 出し方 |
|---|---|---|
| 日暈・幻日・環天頂アーク | 薄い巻層雲・巻雲の氷の粒で光が屈折・反射（環天頂アークは太陽の高さ 32° 以下、幻日は太陽が低いとき） | 雲の種類は今のデータでは分からないため、「起きた」とは出さない。太陽の高さが条件に合う時間帯を「見られるかもしれない」として、観察の手引き（何を・どの方向に）を出す |

- 起きたかどうかを確かめられないものを「起きた」と見せない（取れなかったものを「ない」と見せない、の裏返し）。
